# Roadmap

## CMI movement-speed indicator and presets

- [ ] Add an optional smaller-font line showing the current CMI walk speed or fly speed, with its own display toggle.
- [ ] Explore mouse interaction only while the Minecraft chat screen is open, so normal world clicks are never captured by the HUD.
- [ ] Allow the active walk/fly speed to cycle between `1×`, `2.5×`, and `5×` presets.
- [ ] Make the active movement type and selected value visually unambiguous before changing anything.
- [ ] Verify CMI's supported command or API, live effective-speed source, permissions, denial response, and server acknowledgement before implementation. Fail closed or show unavailable when CMI cannot be confirmed.
